第六章　高频陷阱与破解方法

陷阱典型录音正确处理
改口We planned Tuesday—actually, make that Thursday.Tuesday ×；Thursday ✓
转折It’s cheap, but too unreliable for us.最终评价偏负面
否定I wouldn’t say it was useless.不是“无用”；语气可能保留
部分同意That’s true to some extent, but…主立场通常在 but 后
列出未选方案We considered A and B; in the end we chose C.只把 C 标为决定
近义替换registration charge ↔ enrolment fee匹配意义，不等原词
代词指代It was cancelled because of this.回看 this 指什么
例子干扰Some cities, such as Tokyo…Tokyo 可能只是例子
程度词slightly / nearly / rarely / mainly保留程度，不能夸大
语气反差Oh, brilliant. Another two-hour delay.字面正面，实际讽刺／不满

连读、弱读与口音：训练方向

  • 连读：pick_it_up、an_hour、turn_off；练习按意义块复述，不必模仿所有细节。
  • 弱读：can / of / to / for 常变轻；不要因为没听清功能词就停止。
  • 缩约：gonna、wanna 等非正式口语形式可能出现；先识别意思。
  • 不同口音：不要只练一种发音。重点仍是重读词、句子节奏和上下文。
  • 听写训练应选 5–15 秒短片段：听三遍 → 对稿 → 标出你漏的是词汇、连读还是注意力。

第七章　Part A 题型策略

1. 填表／填空

  • 先读栏标题，它决定答案类别。
  • 严格看答案长度、单复数和题面已有单位。
  • 答案可先用笔记形态，间隙再补成可辨认英文。

2. Multiple Choice

  • 先比较选项差异，不要把每个选项从头读一遍。
  • 听到某选项的词不代表它正确；问的是最终结论还是某个细节？
  • 排除与录音直接矛盾的选项；剩下两项时，检查程度词与主语。

3. Matching

  • 给每个选项写 1–2 个辨识词；听到同义信息便配对。
  • 若选项可重复／不可重复，先看说明；不要凭习惯。

4. 排序／流程

  • 用 1/2/3 记动作，不要写完整句。
  • 叙述可能回顾过去；区分“讲述次序”与“事件发生次序”。

5. 主旨／目的／态度

  • 开头给主题，结尾常给目的或结论；中间例子只作证据。
  • 态度必须结合用词、重音、语调和上下文，不靠单个情绪词。
5** 判断法 先写“字面事实”，再写“说话者立场”。例如：fact = plan delayed；attitude = relieved rather than annoyed。两者分开可减少被表面词汇误导。

第八章　Part B：听、读、写怎样整合

核心公式 TASK（角色／受众／目的／文体）＋ SOURCES（录音＋Data File）→ SELECT（选相关）→ ADAPT（改写与转语气）→ ORGANISE（结构清晰）→ CHECK（完整准确）。

A. 听录音前：建立任务控制表

检查项要回答的问题简写
Role我是谁？拥有何种身份／权限？R
Audience写给谁？关系正式还是熟悉？A
Purpose通知、说服、投诉、建议还是汇报？P
Genreemail、article、speech、report、proposal…G
Content任务要求必须覆盖哪几项？C1/C2/C3
Tone正式、友善、紧急、谨慎、鼓励？T

B. 录音笔记要带“任务标签”

不要把 Part B 录音全记在一堆。听到信息时尽量标到对应任务：T6-date、T7-prob、T8-quote。若暂时不确定，先标 L（Listening）＋关键词。

C. Data File：先按用途扫读，再精读

  • 看任务指示：它会告诉你哪些资料可能相关。
  • 扫标题、来源、日期、作者和显眼格式，建立资料地图。
  • 按任务寻找证据；用 T6/T7/T8 在资料旁标注。
  • 检查资料是否过时、立场是否偏颇、语气是否需转换。

D. 选择、整合、改写

动作低效做法高分做法
Select看到相关主题便全部抄只选直接服务任务目的的资料
Combine录音和 Data File 各写一段按观点／功能组织，把两源放进同一逻辑
Adapt逐字复制原资料改人称、时态、语气、文体和连接方式
Attribute观点来源不明必要时写 According to… / The survey suggests…
Evaluate把每条资料都当事实识别意见、广告语言、推测与证据强弱
考评局常见提醒 Data File 的原文可能为另一目的而写，不能不加处理地逐字搬到新任务。先问：写给谁、为什么写、需要什么语气？

E. 75 分钟写作分配法（可按题量微调）

阶段建议时间动作
任务地图＋分配5 分钟确认只做 B1 或 B2；列每题内容点
找资料＋搭骨架15–20 分钟把 L / D1 / D2 标到各题；定段落
完成各项任务45–50 分钟先确保全部题都有实质内容
检查5–10 分钟内容点、语气、拼写、单复数、题号

时间只是起点。核心原则：不要用 40 分钟雕琢第一题，导致最后一题空白。字数提示用于帮助组织、时间和任务覆盖；显著过短往往内容不足，显著过长会挤压计划与校对时间。
