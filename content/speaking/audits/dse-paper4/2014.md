# 2014 HKDSE English Language Paper 4 Content Audit

- Accessed: 2026-09-02
- Records audited: 30
- Hidden/mock records: 0
- Overall confidence: high for the 30 Set identities and Part A task structures; medium-high for exact Part B wording because HKEAA no longer exposes a clean public text copy of this retired paper.

## Main finding

The existing library has the correct 2014 Set count and Set sequence, and its Part B lists are substantively consistent with the examination scan and independent question index. The main content defect is Part A: many records flatten the original action-based task into a generic presentation and therefore remove important decision-making context. The previous Context passages are generic templates and are not supported by a source. This audit restores the 30 task structures and replaces every unsupported Context with a clearly labelled original 150–220 word mock passage.

The current library also presents each Part B list in the reverse of the printed-paper progression (analytical questions first rather than personal questions first). Because the integration contract requires stable `question_id` values and order, the audit preserves that order but marks `part_b_order` as `conflict` for every Set. A product-level decision is needed before any later reordering migration.

## Replacement Context quality review

- Context rewrite reviewed: 2026-09-03.
- All 30 replacement Contexts were rewritten as three-paragraph, Set-specific mock texts.
- Length range: 150–166 words.
- Each text uses the concrete setting of its own task, such as an airport shift, a school film day, a dinosaur-research visit or a library subscription decision.
- Generic recommendation language and direct restatement of the discussion-point list were removed.
- Exact-sentence comparison across all 30 texts found no sentence shared by two Contexts.
- Pairwise word 5-gram overlap was checked using intersection divided by the smaller Context's 5-gram set. The maximum observed ratio was 0.000, below the required 0.18 threshold.

## Important limitations

- The HKEAA catalogue is authoritative for publication identity and copyright, but the 2014 paper is retired from the public online catalogue.
- The 60-page scan is the closest available representation of the paper. Its OCR is poor, so exactness claims are limited to fields that can be read consistently and independently corroborated.
- The output deliberately does not reproduce the official Context articles. Each replacement is an original, three-paragraph mock of 150–220 words, is labelled accordingly, and preserves all stable Set, point and question identifiers.
- No 2014 records in the supplied canonical file are hidden or marked as mock; all 30 are student-visible past-paper practice records.
