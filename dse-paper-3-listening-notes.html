第三章　听中：怎么听、怎么跟、怎么不崩

A. 三层听法

层级你要抓什么失手时怎么办
第 1 层：定位现在讲到哪一道题／哪位说话者听专名、主题词、题序关键词
第 2 层：内容答案所需事实、原因、观点或步骤只写核心词，不写整句
第 3 层：核实否定、转折、改口、条件、语气旧答案加叉；保留最后有效版本

B. 信息块（chunk）听法

不要把语流拆成单词。把内容切成意义块，例如：

示例 We were going to meet / at the Central Library / on Friday evening, / but the room is unavailable, / so it’s been moved / to Saturday morning. 笔记：mtg Central Lib; Fri eve × → Sat am

C. 信号词就是路标

功能常见信号笔记动作
转折／修正but, however, actually, rather, instead划掉前项，写后项
原因because, since, due to, the reason is写“原因 → 结果”
结果so, therefore, as a result写“→”
举例for example, such as, like标 ex；别把例子误当主旨
列举first, another, finally写 1/2/3
条件／例外if, unless, provided that, except写 if / unless / EXC
总结／决定overall, in short, we’ve decided圈 final

D. 听不清单词时，用上下文补槽

  • 先判断它是什么：人／物／动作／原因／数字。
  • 用语法边界：冠词后是名词；modal 后是动词；than 前后是比较项。
  • 用语义范围：讲报名流程时，听不清的词多半是表格、截止日期、费用或文件。
  • 不要边听边纠结拼写；先写你听见的近似音或首字母，间隙再补。
Level 3 允许“不完美但不中断”。听不清一个词，不等于听不懂整句；先保留数字、否定、动作和结果。
5** 要分清“说过”与“认可”。某观点可能只是被引用后反驳；高阶题常问 speaker’s view，而非对话中出现过的字面句。

第四章　快速笔记系统

A. 五条铁律

  • 意义优先：写关键词，不写完整句。
  • 一致优先：固定符号反复用，不要临场发明太多。
  • 可恢复优先：缩写必须让未来的你看得懂。
  • 重要信息优先：数字、专名、否定、变化、决定先记。
  • 空间优先：笔记写在对应题目／任务旁；别把答案散在不同页。

B. 通用符号库

符号／缩写意义例子
→ / ←导致／来自rain → cancel
↑ / ↓增加／减少fee ↑ 20%
+ / –优点／缺点；正／负+ cheap; – far
≠ / vs不同／对比online vs F2F
× → ✓错误／改口后的最终答案Fri × → Sat ✓
b/c / so因为／所以late b/c traffic
w/ / w/o有／没有w/o ID
req / opt必须／可选ID req; photo opt
prob / sol问题／解决办法prob noise; sol rm 2
gov / org / ppl政府／机构／人们gov fund org
approx / max / min大约／最多／最少approx 30; max 4
att / op / dec态度／观点／决定att doubtful; dec delay

C. 个人缩写的三种做法

  • 去元音：department → dept；development → dev；management → mgmt。
  • 保留词首：information → info；reservation → res；environment → env。
  • 用类别首字母：reason → R；advantage → A；disadvantage → D；speaker → S1/S2。
不要这样记 不要为了缩写而把熟词变得认不出；不要写只有当下才懂的随意字母；不要花时间把笔记写漂亮。

D. 不同资料的笔记格式

资料类型推荐版式例子
两个说话者分栏或 S1/S2 标签S1 +cost; S2 –quality
步骤编号＋动词1 reg 2 pay 3 email proof
问题—解决prob → solno seats → add online sess
过去—现在—未来P / N / FP free; N $50; F review
比较A vs BA cheap/far; B $/near
资料来源L=录音；D3=Data File 第3项L: date; D3: venue detail

第五章　听力时必须记录什么信息

以下不是每段都全记，而是根据题目筛选。先看答案槽位，再从清单中选择。

信息类型必须注意常见坑
人物／身份姓名拼写、职位、谁说／谁做把提出建议者误当执行者
时间／日期日、月、时间、期限、先后原定日期后被改口
数字／单位价格、百分比、人数、房号、电话13/30、15/50；单位漏写或重复
地点／路线建筑、楼层、方向、入口meeting point 与 destination 混淆
原因／结果什么导致什么只记事件，漏掉因果关系
问题／方案问题、建议、最终采用方案建议 ≠ 决定
比较／变化谁更好、由 A 改 B、增减幅度听到两项但没标方向
条件／例外if、unless、only、except把有条件说成绝对事实
观点／态度支持、怀疑、不满、讽刺、保留只看正面词，忽略语调与 but
行动项谁、做什么、何时完成责任人和任务错配
主旨／目的为何说这段话、希望听众做什么被细节或例子带走
证据／例子支持哪一个观点把例子当中心观点

数字与专名的专门处理

  • 数字先写阿拉伯数字：twenty-five → 25；保留单位：25 mins / $25 / 25%。
  • 听电话号码、编号、网址时，预留分组：9123 4567；B-204；www.___.hk。
  • 专名若题目提供选项，先看拼写；若需自行写，先记音节／首字母，重复播放时补齐。
  • teen / ty：注意重音差异；必要时用上下文核对合理范围。
